# Book-Level Addendum

For a complete book, produce:

## A. 全书总论

1. 核心问题与总体命题
2. 章节结构与推进方式
3. 概念的出现、变化与最终定型
4. 理论谱系及关键对话对象
5. 全书证据结构
6. 总体贡献与局限

## B. 逐章笔记

Each chapter should include:

1. 本章功能
2. 核心问题与命题
3. 论证链
4. 关键概念
5. 主要证据
6. 可靠引文
7. 与前后章的关系
8. 本章局限
9. 对全书主命题的贡献

## C. 回到全书

Identify:

- 理论核心章节；
- 主要承担材料证明的章节；
- 与主命题联系较弱的章节；
- 各章是否共同支撑最终结论；
- 全书内部是否存在概念漂移、重复、断裂或未解决矛盾。
